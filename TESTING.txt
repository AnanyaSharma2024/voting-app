http://localhost:3000/candidate

🧪 STEP 5: VOTER CAST VOTE
🔹 Method: GET
🔹 URL:
http://localhost:3000/candidate/vote/CANDIDATE_ID
CANDIDATE_ID = MongoDB me jo candidate add kiya tha, uska _id.
Example:
63a7f5c8d2a1b5f7c9a1d0f2
🔹 Header:
Authorization: Bearer VOTER_TOKEN
VOTER_TOKEN = step 4 me jo token mila tha voter ko.
🔹 Response (First Vote):
{
  "message": "Vote recorded successfully"
}
🔹 Response (If voter votes again):
{
  "message": "You have already voted"
}
🔹 Notes:
Admins cannot vote. Agar admin token se try karega:
{
  "message": "admin is not allowed"
}
